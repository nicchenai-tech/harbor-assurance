## Mandatory submission components

1. Project description: name, purpose and problem statement.
2. GitHub or GitLab repository with a clear README and setup instructions.
3. Publicly accessible, deployed and functional live prototype link. It must remain accessible during judging.
4. Public slide deck or documentation link covering technical architecture, implementation details, challenges and future roadmap.
5. Demo video, maximum five minutes. YouTube must be Public or Unlisted; Google Drive must be Anyone with the link → Viewer. Each extra30seconds incurs a one-mark deduction.
6. Team details, representative contact details and resumes.
7. Written responses covering problem-solution alignment, AI/cloud integration, user feedback/testing, coding challenges, success metrics and scalability.

## Technical requirements

- AI must be meaningfully incorporated into the core functionality, development or deployment.
- Cloud infrastructure must be used meaningfully. Missing cloud integration may significantly reduce the evaluation score.
- No vendor, language, framework or platform is prescribed.
- Preliminary entries must be at least low-code; pure no-code is not accepted. A semi-working prototype is encouraged.
- Finalists are expected to extend the entry into a fully functional working prototype.
