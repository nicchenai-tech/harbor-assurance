# First-time reviewer test

Use one helper who has not operated Harbor. Do not explain the interface after giving the tasks.

## Tasks

1. Find the case that needs operational attention and name the differing field.
2. Open the SI and BL source evidence for that field.
3. Explain why the equivalent-weight case is not an error.
4. Resolve the missing Notify Party using the BL source and produce report v2.
5. Inspect the scanned case and state whether it is automatically approved.

## Record

- Start/end time and total minutes.
- Tasks completed without help.
- Incorrect conclusions.
- Questions asked.
- Exact labels or controls that caused hesitation.
- One sentence answering: “What does Harbor do better than a plain document chatbot?”

## Acceptance criteria

- All five tasks completed within five minutes.
- Zero incorrect business conclusions.
- No confusion between waiting, verified, mismatch and review.
- Tester can locate evidence and understand that OCR is a proposal.
- Tester can explain that human correction creates a new report version.

Do not invent user-feedback numbers. Add measured results to the submission only after this protocol is actually run.
